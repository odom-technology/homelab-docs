# Glossary

- **Guest:** A VM or container hosted by a hypervisor.
- **Quorum:** The votes required for safe cluster configuration changes.
- **Recovery point objective:** Maximum acceptable data loss measured in time.
- **Recovery time objective:** Target time to restore a service.
- **Tailnet:** A private network formed by Tailscale devices and policy.
- **Trust boundary:** A point where data or control crosses between security contexts.
